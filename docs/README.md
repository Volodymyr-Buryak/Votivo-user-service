# Документация User Service

- [OpenAPI](openapi.yaml) — контракт HTTP API: операции, модели, валидация, аутентификация и ошибки.
- [Реализация](implementation.md) — слои приложения, данные, Keycloak, RabbitMQ, безопасность, запуск и ограничения.
- [Запуск проекта](../README.md) — краткая инструкция из корня репозитория.

Спецификация ведётся вручную по текущему коду. При изменении контроллеров, DTO или правил доступа обновляйте `openapi.yaml`. Swagger UI и автоматическая публикация `/v3/api-docs` в приложение не добавлены.
